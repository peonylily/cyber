# Cyber Mentor | المرشد السيبراني

منصة عربية تعليمية تفاعلية للتوعية بالأمن السيبراني، بهوية بصرية مستوحاة من مراكز عمليات الأمن السيبراني (SOC). تضم اختبارًا من 15 سؤالًا، نموذج شجرة قرار، خطة تعلم مخصصة، ثلاثة مسارات تعليمية، تحديات مواقف، وصفحة منهجية ومقاييس تقييم.

## المزايا
- واجهة عربية RTL بتصميم داكن تقني.
- اختبار تفاعلي: 15 سؤالًا موزعة بالتساوي على التصيد والخصوصية وكلمات المرور.
- شجرة قرار فعلية من `scikit-learn` تتنبأ بأولوية المسار من درجات المجالات وعدد الأخطاء.
- تقرير درجات وتوصيات مرتبطة بالمسار الناتج.
- مركز تعلم بثلاثة مسارات، مع محتوى وممارسات.
- تحديات مواقف مع تغذية راجعة تفسيرية.
- صفحة منهجية تعرض Accuracy وPrecision وRecall ومصفوفة الالتباس.
- لا يحتاج إلى قاعدة بيانات أو مفاتيح API؛ نتائج الاختبار محفوظة في جلسة التطبيق فقط.

## تشغيل محليًا
يتطلب Python 3.10 أو أحدث.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## إعادة توليد البيانات وتقييم النموذج

```bash
python generate_data.py
python train_model.py
```

البيانات الموجودة في `data.csv` اصطناعية بالكامل، مولدة ببذرة ثابتة. الفئة المرجعية هي المجال الأقل درجة وفق قاعدة برمجية محددة، لذا يتعلم النموذج تقريب هذه القاعدة. لا تمثل البيانات طلابًا حقيقيين، ولا يجوز وصف الدقة الناتجة بأنها دقة ميدانية أو دليل على تحسن التعلم.

## النشر على Streamlit Community Cloud
1. أنشئ مستودع GitHub باسم `cyber-mentor` وارفع محتويات هذا المجلد.
2. افتح Streamlit Community Cloud وسجّل الدخول وفق متطلبات الخدمة وشروط العمر، وبمساعدة ولي الأمر عند الحاجة.
3. اختر المستودع والفرع `main` والملف الرئيسي `app.py`.
4. ابدأ النشر. لا توجد أسرار أو مفاتيح API مطلوبة.

## منهجية التقييم
- تقسيم طبقي إلى تدريب واختبار بنسبة 75% / 25% مع `random_state=47`.
- شجرة قرار بعمق أقصى 4، وحد أدنى 4 عينات في الورقة.
- المقاييس: Accuracy، وPrecision موزون، وRecall موزون، ومصفوفة الالتباس.
- يعرض التطبيق المقاييس المحسوبة عند التشغيل من ملف البيانات الحالي.

**حدود مهمة:** الاختبار أداة تعلم ذاتي قصيرة، وليس اختبارًا معياريًا أو شهادة كفاءة. احتمالية النموذج ليست احتمالًا موثوقًا لمستوى المتعلم. قبل استخدام بحثي أو إصدار ادعاءات عن الفاعلية، يجب تحكيم الأسئلة، وجمع بيانات حقيقية بموافقة الجهة المعنية، وتحديد بروتوكول تقييم مسبق، وإجراء تحقق مستقل على عينة مناسبة.

## الخصوصية والسلامة
- لا تجمع المنصة الاسم أو البريد أو كلمات المرور أو بيانات تعريفية.
- لا تدخل أي معلومات شخصية أو كلمات مرور حقيقية.
- لا تفحص أجهزة أو شبكات ولا تنفذ اختبار اختراق.
- المحتوى توعوي عام، وليس بديلًا عن سياسات الأمن السيبراني المعتمدة في المدرسة أو المؤسسة.
